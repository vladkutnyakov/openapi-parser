# openapi-parser

Инструмент для фронтенд-разработки: выбираете эндпоинт из OpenAPI 3.x спеки — получаете готовые TypeScript-типы для path/query-параметров, тела запроса, ответов и всех задействованных DTO с оригинальными именами бэкенда.

Зачем: чтобы не переписывать типы из Swagger UI вручную и не сверять контракты глазами, когда бэкенд их меняет. Для второго есть сравнение — вставляете свой тип из кода и видите по полям, что разошлось с контрактом.

Работает как локальная веб-страница и как расширение VSCode.

## Как пользоваться

### Запуск

Веб-версия:

```bash
npm install
npm run dev
```

и открыть http://localhost:5173.

Расширение VSCode:

```bash
npm install
npm run build:vsix
code --install-extension apps/vscode/openapi-parser.vsix
```

Панель открывается командой «OpenAPI Types Tools: Open panel» (Ctrl+Shift+P) или кнопкой `{→}` на вкладке редактора.

### Работа

1. В верхнем поле укажите источник спеки — путь к файлу (`C:\specs\api.json`) или URL (`http://backend-host/v3/api-docs`).
2. Выберите эндпоинт в списке слева — справа появятся типы.
3. Скопируйте нужный тип кнопкой у блока или всё сразу кнопкой вверху.
4. Чтобы проверить свой тип, нажмите «Сравнить» у блока и вставьте тип из кода.

Если в проекте свои конвенции (`| null` вместо `?`, без точек с запятой и т.п.), задайте их в редакторе правил — кнопка **⚙**. Подробно — в [HOOKS.md](HOOKS.md).
