# OpenAPI Types Tools

Панель для VSCode: находит эндпоинт в OpenAPI 3.x спеке и генерирует готовые TypeScript-типы — path/query-параметры, тип тела запроса, типы ответов и все задействованные DTO с оригинальными именами бэкенда.

## Как пользоваться

Два способа открыть панель:

- **кнопка `{→}` на вкладке** (рядом со «Split Editor Right») — панель откроется сбоку; если открытый файл лежит на диске, он сразу и загрузится как спека;
- **команда «OpenAPI Types Tools: Open panel»** из палитры (Ctrl+Shift+P) — откроет панель с последним использованным источником.

В верхнем поле — источник спеки:

- путь к файлу: `C:\specs\api.json` (относительные пути считаются от корня проекта)
- URL: `http://backend-host/v3/api-docs`

Спеку читает сам редактор, поэтому ни CORS, ни запущенный сервер не нужны.

## Возможности

- **Правила генерации** (кнопка ⚙) — конвенции вашего бэкенда задаются JS-хуками, с живым предпросмотром. Пресеты переживают перезапуск редактора; правила можно загрузить из `.js`-файла и сохранить в него, чтобы держать общий стиль команды рядом с кодом.
- **Читаемый вывод** — типы сгруппированы в сворачиваемые секции (path- и query-параметры, тело запроса, ответы, DTO), у каждой своя кнопка копирования. Ctrl+F ищет по сгенерированным типам: совпадения подсвечиваются, Enter и Shift+Enter ходят по ним, свёрнутая секция с совпадением разворачивается сама.
- **Факты об эндпоинте вне кода** — метод, путь и краткое описание стоят заголовком, у каждого ответа виден статус и описание: их рисует панель, а не комментарии в типе, где они выцветали наравне с описаниями полей. Клик по пути копирует его. Рядом с телом запроса и каждым ответом показан Content-Type — для `multipart/form-data` и JSON сгенерированный TypeScript одинаков, а отправляются они по-разному; если типов контента несколько, остальные перечислены рядом.
- **Сравнение типов** — вставьте свой тип из кода, панель покажет по полям, что разошлось с контрактом. Сравнение семантическое: порядок полей и форматирование отличиями не считаются.
- **Закрытые авторизацией спеки** — если источник отвечает редиректом на форму логина, панель предложит войти и вставить куку. Кука хранится в защищённом хранилище VSCode.
- **Русский и английский** — язык интерфейса берётся из языка редактора и переключается кнопкой `RU`/`EN`, выбор запоминается. Комментарии в сгенерированном коде остаются английскими: этот код уезжает в ваш репозиторий.

Панель наследует тему редактора, копирование идёт в буфер обмена VSCode.
