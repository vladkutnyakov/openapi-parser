# OpenAPI Types Tools

Выбираете эндпоинт из OpenAPI 3.x спеки — получаете готовые TypeScript-типы: path/query-параметры, тело запроса, ответы и все задействованные DTO с оригинальными именами бэкенда.

Чтобы не переписывать типы из Swagger UI вручную и не сверять контракты глазами, когда бэкенд их меняет.

## Как пользоваться

1. Откройте панель:
   - кнопкой `{→}` на вкладке редактора — панель откроется сбоку и загрузит открытый файл как спеку;
   - или командой **OpenAPI Types Tools: Open panel** (Ctrl+Shift+P) — откроется с последним источником.
2. В верхнем поле укажите источник спеки — путь к файлу (`C:\specs\api.json`) или URL (`http://backend-host/v3/api-docs`).
3. Выберите эндпоинт слева — справа появятся типы.
4. Скопируйте нужный тип кнопкой у блока или всё сразу кнопкой вверху.

## Возможности

- **Сравнение типов** — нажмите «Сравнить» у блока, вставьте свой тип из кода и увидите по полям, что разошлось с контрактом.
- **Правила генерации** (кнопка ⚙) — подстройте вывод под конвенции проекта (`| null` вместо `?`, без точек с запятой и т.п.) JS-хуками с живым предпросмотром. Правила можно сохранить в `.js`-файл и держать общими для команды.
- **Поиск** — Ctrl+F ищет по сгенерированным типам.
- **Закрытые авторизацией спеки** — если источник уводит на форму логина, панель предложит войти и вставить куку.
- **Русский и английский** интерфейс, переключается кнопкой `RU`/`EN`.

Панель подстраивается под тему редактора.

## Требования

VSCode 1.90 или новее. Всё работает локально, никуда ничего не отправляется.
